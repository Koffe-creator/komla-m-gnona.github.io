# komlagnona.com

My personal site. Plain HTML, CSS and a little JavaScript. No framework, no build step.

Live at <https://www.komlagnona.com>

## Editing

All the content is in `index.html`. Styling is in `styles.css`, with the colors set
as variables at the top.

To preview it locally:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

Pushing to `main` publishes the site.
